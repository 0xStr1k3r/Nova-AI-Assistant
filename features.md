# Nova Features

Nova is a voice-first AI assistant with automation, memory, and agent orchestration across desktop, browser, and messaging channels.

## Core Voice Experience
- Real-time Gemini Live conversation
- Browser-native wake word and microphone capture
- Voice profiles and speaker gating
- Configurable operating modes for safety and capability control

## Memory and Context
- Persistent user memory across sessions
- Semantic memory and context retrieval
- Conversation/session logging
- Settings for identity, wake word, and saved preferences

## Browser Automation
- Automated search and navigation
- Page extraction and structured content handling
- Visual analysis with screenshot-based reasoning
- Human-like interaction: click, type, drag, scroll, shortcuts
- Tabs, bookmarks, cookies, PDF capture, and media control
- OCR-based page reading and click recovery

## Desktop Automation
- Desktop screenshots and screen analysis
- Window listing, focus, maximize, minimize, close
- Keyboard and mouse simulation
- App launching and system information
- Wayland and X11 support

## Agent and Channel Operations
- Multi-channel messaging architecture
- Agent monitoring and status panels
- Scheduled task execution
- System observer and proactive notifications
- Workflow recording and execution
- Container and workspace isolation

## Integrations
- GoDo task manager support
- Obsidian vault workflows
- Custom NVIDIA coding agent integration
- Multi-channel adapters such as Telegram, Discord, and Slack

## Dashboard and Controls
- Multi-tenant dashboard
- Tenant analytics and traffic overview
- Live task, channel, observer, and workflow panels
- Real-time agent control from the UI
